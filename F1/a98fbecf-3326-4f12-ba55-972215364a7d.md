## Floricode API

**NL**

Haalt gestandaardiseerde Floricode-codelijsten via de API op en werkt de bijbehorende codes in Florisoft bij.

**EN**

Retrieves standardized Floricode code lists through the API and updates the related codes in Florisoft.
