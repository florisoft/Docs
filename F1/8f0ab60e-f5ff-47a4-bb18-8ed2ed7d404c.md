Florisoft .Net Server Voorraad Component

## Server Stock Component

**NL**

Publiceert beschikbare voorraad vanuit de serveromgeving naar aangesloten client- en verkoopkanalen.

**EN**

Publishes available stock from the server environment to connected client and sales channels.
